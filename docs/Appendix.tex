\subsection*{Appendix C: Detailed User Manual}
This section provides a step-by-step guide for each actor type to effectively utilize the FootField platform.

\subsubsection{Provider Admin: Managing the Ecosystem}
\begin{enumerate}
    \item \textbf{Login:} Access \texttt{admin.footfield.app} and enter your super-admin credentials.
    \item \textbf{Tenant Overview:} View the "Tenant Matrix" to see active vs. suspended facilities.
    \item \textbf{Provisioning:} To onboard a new facility, click "Add Tenant," enter their business name, and assign a subscription package (Basic, Standard, or Premium).
    \item \textbf{Billing:} Access the "Invoices" tab to monitor monthly subscription revenue from all tenants.
\end{enumerate}

\subsubsection{Tenant Admin: Daily Facility Operations}
\begin{enumerate}
    \item \textbf{Dashboard:} Log in to your unique facility subdomain. The home screen shows a 24-hour revenue trend and upcoming bookings.
    \item \textbf{Field Setup:} Navigate to "Manage Fields" to define your pitch sizes and dynamic pricing (e.g., higher rates after 5:00 PM).
    \item \textbf{Real-time Schedule:} Use the "Grid View" to drag and drop manual bookings for walk-in customers.
    \item \textbf{Reporting:} Go to "Analytics" to generate a monthly performance report, which can be exported to PDF for tax purposes.
\end{enumerate}

\subsubsection{Customer: Finding and Booking a Match}
\begin{enumerate}
    \item \textbf{Storefront:} Open the facility's public booking link on your mobile browser.
    \item \textbf{AI Booking:} Tap the "AI Assistant" bubble. Type: "I want a 7-a-side field for Saturday morning."
    \item \textbf{Confirmation:} The AI will present available slots. Select one and provide your contact details.
    \item \textbf{Payment:} You will be redirected to the secure VNPay gateway. Choose your bank app or scan the VNPAY-QR.
    \item \textbf{Ticket:} Once paid, your QR code ticket will be sent via email and displayed on the screen. Save this for check-in.
\end{enumerate}

\subsection*{Appendix E: Deployment and Troubleshooting Guide}

\textbf{1. Deployment Steps (Production):}
\begin{enumerate}
    \item \textbf{Database:} Create a MySQL instance on Aiven. Run the Knex migrations: \texttt{npx knex migrate:latest}.
    \item \textbf{Environment:} Set up GEMINI\_API\_KEY, VNP\_HASH\_SECRET, and CLOUDINARY\_URL on Render.
    \item \textbf{Build:} Connect Render to the GitHub repository. Set build command: \texttt{npm install} and start command: \texttt{node src/index.js}.
\end{enumerate}

\textbf{2. Troubleshooting Common Issues:}
\begin{itemize}
    \item \textbf{AI Latency:} Ensure the Google Cloud region for Gemini is close to your application server region.
    \item \textbf{Database Connection:} Verify that the Aiven IP address is whitelisted in Render's outgoing firewall.
    \item \textbf{Mobile Camera Access:} Ensure that the Android Manifest includes \texttt{android.permission.CAMERA}.
\end{itemize}
